Five ways to say
the same thing.

The same person, the same work, five different arguments about how a homepage should behave. Each one is a single hand-written page — open any of them, resize the window, move the cursor.

01 Paper Editorial print layout. Serif display, rules, a running index, reading progress. Fraunces · reading progress ↗ 02 Terminal The whole site is a shell. Type help, ls, cat lab; it answers. JetBrains Mono · command parser ↗ 03 Kinetic Swiss poster type with a marquee that reacts to scroll velocity and a horizontal rail. Archivo Black · scroll velocity ↗ 04 Spatial A generative flow field under quiet type. Move the cursor to push it around; click to scatter it. Syne · canvas particle field ↗ 05 Brutal Acid yellow, hard shadows, a sticker you can drag, buttons that lean toward the cursor. Bricolage · magnetic buttons ↗

Notes

Every page is static: one HTML file, one stylesheet, one script, no build step and no dependencies beyond a Google Fonts request.

All five respect prefers-reduced-motion, work without a mouse, and keep their text in the HTML rather than in a canvas.
