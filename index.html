Eight ways to say
the same thing.

The same person, the same work, eight different arguments about how a homepage should behave. Each one is a single hand-written page — open any of them, resize the window, move the cursor.

01 Paper Editorial print layout. Serif display, rules, a running index, reading progress. Fraunces · reading progress ↗ 02 Terminal The whole site is a shell. Type help, ls, cat lab; it answers. JetBrains Mono · command parser ↗ 03 Kinetic Swiss poster type with a marquee that reacts to scroll velocity and a horizontal rail. Archivo Black · scroll velocity ↗ 04 Spatial A generative flow field under quiet type. Move the cursor to push it around; click to scatter it. Syne · canvas particle field ↗ 05 Brutal Acid yellow, hard shadows, a sticker you can drag, buttons that lean toward the cursor. Bricolage · magnetic buttons ↗ 06 Blueprint A technical drawing: construction grid, dimension lines, leader annotations and a title block with a revision. Space Grotesk · live crosshair, CSS grid paper ↗ 07 Aurora Depth through light — three drifting gradient fields under frosted glass, with gradient-cut serif type. Instrument Serif · backdrop-filter, parallax orbs ↗ 08 Ledger The portfolio as a dataset: filter it, sort it, walk it with the arrow keys, read the record pane. Space Grotesk · client-side table, keyboard nav ↗

Notes

Every page is static: one HTML file, one stylesheet, one script, no build step and self-hosted fonts, no external requests.

All eight respect prefers-reduced-motion, work without a mouse, and keep their text in the HTML rather than in a canvas.
